# د ښوونځي مدیریت — ډیسکټاپ

د ښوونځي او مدرسې د کنټرول بشپړ سیسټم. **بې‌انټرنټه** کار کوي؛ ټول
معلومات په یوه SQLite فایل کې دي چې مسیر يې کارن پخپله ټاکي.

## ټکنالوژي

| برخه | انتخاب | ولې |
|---|---|---|
| چوکاټ | Flutter (Dart) | ریښتینی رینډر — WebView نه دی |
| ډیټابیس | SQLite + drift | type-safe، reactive، له isolate سره |
| فونټ | Vazirmatn (بسته شوی) | پښتو/دري/انګلیسي، له انټرنټه نه راښکل کېږي |
| وینډو | window_manager | د ریښتیني ډیسکټاپ سافټویر چلند |

## چلول

```bash
flutter pub get
dart run build_runner build      # د drift کوډ تولید
flutter run -d windows           # یا -d linux
```

> د ډیټابیس د سکیما بدلولو وروسته `build_runner` بیا وځغلوئ.

## ازموینې

```bash
flutter test                          # ټولې
flutter test test/performance_test.dart   # د کارکړنې
```

## د کارکړنې ریښتینې شمېرې

د یوه ښوونځي د یوه کال ډیټا — **۸۵۰ شاګردان × ۲۰۰ ورځې = ۱۷۰,۰۰۰
د حاضرۍ کرښې**:

| کار | وخت |
|---|---|
| ۱۷۰,۰۰۰ کرښې لیکل | ۱۹۲۰ms |
| د یوه شاګرد کلنۍ حاضري | **۱۱.۶ms** |
| د یوې ورځې غیرحاضران | **۱.۵ms** |
| د ټول کال ټولټال (GROUP BY) | **۳۱ms** |

د پوښتنې پلان: `SEARCH attendances USING INDEX ix_att_student_date`

**پایله:** د ریکارډونو د مدیریت سرعت ژبه نه ټاکي — **index** يې ټاکي.
دا شمېرې د `test/performance_test.dart` له خوا هر ځل بیا تاییدېږي.

## جوړښت

```
lib/
├── core/
│   ├── config/     د تنظیماتو فایل — د ډیټابیس مسیر دلته ساتل کېږي
│   ├── l10n/       درې ژبې؛ په UI کې هېڅ متن سخت نه دی لیکل شوی
│   ├── theme/      رنګ، فونټ، انیمیشن — ټول ټوکنونه یو ځای
│   └── utils/      د پاسورډ هش او نور
├── data/db/        د drift سکیما، migrations، index‌ونه
└── features/
    ├── setup/      د لومړي ران ویزارډ (د ډیټابیس مسیر ټاکنه)
    ├── auth/       ننوتل، رولونه، د حساب قفل
    ├── shell/      سایډبار + پورتنۍ کرښه
    └── dashboard/  KPI کارتونه او چارټ
```

## د جوړښت پرېکړې

**حفظ = عادي شاګرد.** د حفظ شاګردان جلا ډول نه دي — هماغه د `students`
جدول، هماغه د داخلې بهیر، هماغه آی‌ډي کارت او حاضري. د سبق/سبقي/منزل
تعقیب یوازې یوه **اضافي پاڼه** ده چې د شاګرد پر دوسیه ورزیاتېږي، کله
چې د ښوونځي ډول `madrasa` یا `both` وي. نو د شاګردانو سکیما دوه‌برخې
کولو ته اړتیا نلري.

**د ښودنې شمېرې ختیځې، د ډیټا شمېرې لاتیني.** په UI کې ۸۴۲ ښکاري، خو
په ډیټابیس، د داخلې نمبرونو او QR کوډونو کې تل `842` پاتې کېږي. که نه،
لټون او بارکوډ سکینر به مات شي. د لټون خانه دواړه بڼې مني.

## بسته‌بندي (exe او apk)

GitHub Actions پر هر push بسته جوړوي — `.github/workflows/build.yml`.

| څه | چېرې | حالت |
|---|---|---|
| `SchoolManager-Windows.zip` | Actions ← Artifacts | ✅ چمتو |
| `SchoolManager.apk` | Actions ← Artifacts | ⏳ د `mobile/` په جوړېدو سره |

**د ډاونلوډ لار:** GitHub → Actions → وروستی بریالی run → د پاڼې په
پای کې *Artifacts*.

**د نسخې خپرول:** یو ټګ ولیکئ (`git tag v0.1.0 && git push --tags`) —
Release پخپله جوړېږي او فایلونه پکې ځړول کېږي.

> **مهم:** zip **ټوله** پوښۍ لري، نه یوازې `.exe`. Flutter د DLL
> فایلونو او د `data/` پوښۍ سره ځغلي — یوازې `.exe` نه چلېږي.

### لاسلیک (اختیاري)

که لاندې secrets ورزیات شي، بسته لاسلیک کېږي. پرته له هغې هم جوړېږي
او کار کوي، خو ویندوز به د لومړي ران پر مهال د SmartScreen خبرداری
وښیي:

| Secret | څه شی |
|---|---|
| `WINDOWS_PFX_BASE64` | د `.pfx` سند base64 |
| `WINDOWS_PFX_PASS` | د هغه پاسورډ |
| `ANDROID_KEYSTORE_BASE64` | د اندروید keystore base64 |
| `ANDROID_STORE_PASS` | د هغه پاسورډ |

### د Flutter نسخه ولې تړل شوې ده؟

`build.yml` کې `3.29.0` ټاکل شوې، نه `stable`. ځکه چې `stable` هره څو
اونۍ بدلېږي او د Flutter د API بدلونونه کوډ ماتوي (بېلګه: `CardTheme`
په ۳.۳۲ کې `CardThemeData` شو). که نسخه ونه تړل شي، یوه ورځ به build
پرته له دې چې موږ څه بدل کړي وي، سور شي.

## د لومړي پړاو حالت

**جوړ شوی:**

- د لومړي ران ویزارډ — د ډرایو ټاکنه، د لیکلو ازموینه، د پاتې ځای
  ښودنه، د موجود ډیټابیس پرانیستل
- بشپړه ډیټابیس سکیما — ۱۵ جدولونه، ۱۴ index، migrations
- ننوتل — PBKDF2، د حساب قفل، د تفتیش لاګ
- رنګین سایډبار — د ټولېدو وړ، د هر ماډل خپل رنګ، رول‌پر‌بنسټ ښودنه
- ډاشبورډ — ګرادیانټ KPI کارتونه، چارټ، د شمېرلو انیمیشن
- درې ژبې + RTL + تیاره/روښانه حالت
- ۱۷ ازموینې (اوس ټولټال ۴۳)

**دویم پړاو (روان):**

- د شاګردانو ماډل — لیست، لټون، سرغړاوی، پاڼې
- د QR کارت کوډ له HMAC لاسلیک سره (جعلي کارت نه منل کېږي)
- د داخلې راکړه‌ورکړه — شاګرد + سرپرستان + ثبت یوځای
- `DataTableView` چې ټول راتلونکي ماډلونه يې کاروي

**پاتې:** د داخلې ویزارډ، د آی‌ډي کارت ډیزاینر، استادان، ټولګي.
