# د ښوونځي مدیریت — ډیسکټاپ

د ښوونځي او مدرسې د کنټرول بشپړ سیسټم. **بې‌انټرنټه** کار کوي؛ ټول
معلومات په یوه SQLite فایل کې دي چې مسیر يې کارن پخپله ټاکي.

## ټکنالوژي

| برخه | انتخاب | ولې |
|---|---|---|
| چوکاټ | Flutter (Dart) | ریښتینی رینډر — WebView نه دی |
| ډیټابیس | SQLite + drift | type-safe، reactive، له isolate سره |
| فونټ | Vazirmatn (بسته شوی) | پښتو/دري/انګلیسي، له انټرنټه نه راښکل کېږي |
| وینډو | window_manager | د ریښتیني ډیسکټاپ سافټویر چلند |

## چلول

```bash
flutter pub get
dart run build_runner build      # د drift کوډ تولید
flutter run -d windows           # یا -d linux
```

> د ډیټابیس د سکیما بدلولو وروسته `build_runner` بیا وځغلوئ.

## ازموینې

```bash
flutter test                          # ټولې
flutter test test/performance_test.dart   # د کارکړنې
```

## د کارکړنې ریښتینې شمېرې

د یوه ښوونځي د یوه کال ډیټا — **۸۵۰ شاګردان × ۲۰۰ ورځې = ۱۷۰,۰۰۰
د حاضرۍ کرښې**:

| کار | وخت |
|---|---|
| ۱۷۰,۰۰۰ کرښې لیکل | ۱۹۲۰ms |
| د یوه شاګرد کلنۍ حاضري | **۱۱.۶ms** |
| د یوې ورځې غیرحاضران | **۱.۵ms** |
| د ټول کال ټولټال (GROUP BY) | **۳۱ms** |

د پوښتنې پلان: `SEARCH attendances USING INDEX ix_att_student_date`

**پایله:** د ریکارډونو د مدیریت سرعت ژبه نه ټاکي — **index** يې ټاکي.
دا شمېرې د `test/performance_test.dart` له خوا هر ځل بیا تاییدېږي.

## جوړښت

```
lib/
├── core/
│   ├── config/     د تنظیماتو فایل — د ډیټابیس مسیر دلته ساتل کېږي
│   ├── l10n/       درې ژبې؛ په UI کې هېڅ متن سخت نه دی لیکل شوی
│   ├── theme/      رنګ، فونټ، انیمیشن — ټول ټوکنونه یو ځای
│   └── utils/      د پاسورډ هش او نور
├── data/db/        د drift سکیما، migrations، index‌ونه
└── features/
    ├── setup/      د لومړي ران ویزارډ (د ډیټابیس مسیر ټاکنه)
    ├── auth/       ننوتل، رولونه، د حساب قفل
    ├── shell/      سایډبار + پورتنۍ کرښه
    └── dashboard/  KPI کارتونه او چارټ
```

## د لومړي پړاو حالت

**جوړ شوی:**

- د لومړي ران ویزارډ — د ډرایو ټاکنه، د لیکلو ازموینه، د پاتې ځای
  ښودنه، د موجود ډیټابیس پرانیستل
- بشپړه ډیټابیس سکیما — ۱۵ جدولونه، ۱۴ index، migrations
- ننوتل — PBKDF2، د حساب قفل، د تفتیش لاګ
- رنګین سایډبار — د ټولېدو وړ، د هر ماډل خپل رنګ، رول‌پر‌بنسټ ښودنه
- ډاشبورډ — ګرادیانټ KPI کارتونه، چارټ، د شمېرلو انیمیشن
- درې ژبې + RTL + تیاره/روښانه حالت
- ۱۷ ازموینې

**راتلونکی پړاو:** شاګردان، استادان، ټولګي، د داخلې ویزارډ،
د آی‌ډي کارت او QR تولید.
